## Primeiro lote de implementação

Executar **T001 → T002 → T003 → T004 → T005 → T006 → T007**, apenas com as respectivas dependências cumpridas. O lote encerra na infraestrutura de dados; não inclui T008 ou tarefas de fases posteriores. Docker indisponível ou imagem não confirmada bloqueiam o trabalho dependente; não marcar infraestrutura como validada nem usar instalação local alternativa. Este planejamento não executa esse lote.
